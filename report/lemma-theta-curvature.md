The bulk width is fixed by the same number as the
eigenvalue:

    ψ(t) ≈ ψ_mid exp( − (−ln λ₀)/L²  (t − L/2)² )

Four-mode wall then doubles the edge relative to
this Gaussian tail (a L²/4 → a L²/2), and Q
squares that (×2), which is why
−ln λ₀ ≈ a L² in the first place.

One parameter. The lemma has no extra C in the
bulk.
