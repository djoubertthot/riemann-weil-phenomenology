# Slepian of the desert, as a test function for Q

Band [0, γ₁] on the window [0, L],
top prolate expanded in the same
hats as Q. R = Rayleigh of Q on
that vector. R ≥ λ₀(Q), so
ell_S := −ln R ≤ ell_Q.

λ_prolate ≈ 1: time-bandwidth
γ₁ L / 2 is large, the function
really lives in the desert.

It is still a bad ground state.
ell_Q ≈ 2 · ell_S on the wide
deserts (27/12, 35/16, 49/18),
worse on the narrow ones
(10/3, 8/2). Q cancels on the
zeros 10⁶–10¹⁵ times better than
the pure desert Slepian.

## Reading

The minimizer of Q uses the later
zeros, not only the hole [0,γ₁].
A proof of Lemma 2 that inserts
the Slepian of the desert into Q
gives the lower bound

    ell_Q ≥ ell_S ≈ O(τγ₁)

(here ell_S / τγ₁ ~ 1.3–1.5 on
χ₅/χ₃), which we already had,
and misses a factor two to six
in the exponent that is the
rest of Γ.

The circularity of the last note
is now quantitative: the object
that reaches ell_Q is Q's own
ground state, not a Slepian you
can write by hand.
