# 0.703 is 1/√2

A delta at L/2 against the ONB

    η₀ = L^{−1/2},     η₁ = (2/L)^{1/2} cos(2π t / L)

gives ⟨δ, η₀⟩ / |⟨δ, η₁⟩| = 1/√2, because
cos(2π · (L/2) / L) = −1.

A Gaussian of curvature a only multiplies that
ratio by the form factor ĉ₀/ĉ₁ = exp(π² / (a L²))
= exp(π² / (−ln λ₀)). Hence

    v₀ / |v₁|  =  (1/√2) · exp(π² / (−ln λ₀)).

The 30 % was the missing ONB √2 on the
constant mode. No extra Weil number.
The edge law is now

    ψ(t) ≈ ψ_mid exp(− (−ln λ₀)/L² (t−L/2)²)
           in the bulk,

    v₀ / |v₁| = 2^{−1/2} exp(π² / (−ln λ₀)),

    −ln|ψ(0)| = (−ln λ₀)/2 + O(1),

with the O(1) the residual of four-mode
truncation. χ₅ is the first check that
1/√2 survives a different Γ_ℝ.
