# C converges to 1/(4e) by adding the Gaussian rungs

ζ, µ=11, dps=22 (full-Q λ is noise at this dps;
true C uses the 30-digit run: 0.087).

| space | λ | ψ(0) | C | v₀/|v₁| |
|---|---|---|---|---|
| span{e₀,e₁} | 7.4×10⁻⁶ | 6.8×10⁻³ | **0.162** | 1.43 |
| span{e₀…e₃} | 3.0×10⁻¹² | 5.2×10⁻⁶ | **0.112** | 0.99 |
| full Q (30 d) | 8.9×10⁻²² | ~ e^{-23} | **0.087** | 0.86 |
| 1/(4e) | | | **0.092** | |

Two modes overshoot C by ×1.8. Modes 2 and 3
— the same rungs that take λ from 10⁻³ to
10⁻²¹ — bring C down to 1/(4e). The axis
2×2 (v_arch, v_towers) is the wrong plane
for C: its λ is still 10⁻³.

So 1/(4e) on ζ is the four-mode value of
λ/ψ(0)², not a pairing of the two raw
standard-basis vectors. Off ζ those rungs
never turn on (N_eff frozen at 2) and C
stays at the two-mode size 0.12–0.16.
That is consistent with χ₅, χ₄, χ₃.
