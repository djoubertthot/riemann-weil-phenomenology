# Pole term in Q_ζ

ξ(s) = s(s−1)π^{−s/2}Γ(s/2)ζ(s) has poles
cancelled; the completed Λ still knows the
trivial factors. In spectro_zeta the explicit
formula keeps a compact term

    POLE_{nm} = ∫_0^L θ_nm(y) (e^{y/2}+e^{−y/2}) dy

which is ĥ(g) at the points 0 and 1
(the poles of ζ / the factors s(s−1)).

At μ=2 N=7 (only p=2, and θ_00(log 2)=0):

    mode 0: POLE +1.106, ARCH −1.105, T2 ≈ 0
            λ = 0.0015
    mode 1+: POLE small, ARCH ≈ λ

The ground state of Q_ζ is the pole–arch
near-cancellation, not a desert of zeros
(γ1=14 is invisible at L=log 2). At μ=4
the same cancellation is 10^{-12}: more
panels, better cancellation, smaller λ0.

This mode must be discarded or projected
before comparing to Gram. It is an artifact
of keeping ĥ(g)(0)+ĥ(g)(1) inside a window
that does not see t=14.
