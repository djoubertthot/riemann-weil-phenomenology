# Project out the rank-1 residual (χ₂₉ μ=11)

G₁ = G − σ₀ u vᵀ.

| | λ0 | G/Q |
|---|-----|-----|
| raw | Q=0.303, G=0.281 | 0.929 |
| G−σ₀uvᵀ | 0.302 | **0.997** |

||G₁−Q||_F / ||Q||_F = **0.23 %** (was 6.5 %).
v₀ᵀ G₁ v₀ = 0.302 vs v₀ᵀ Q v₀ = 0.303.

The 7 % on the singlet was leakage of the
high-k channel (overlap only 0.09, Rayleigh
still −0.015). After the projection the
Weil identity holds at 0.3 % on v0 and at
0.23 % in Frobenius.

This is a cutoff mode, not an off-line zero.
It does not prove RH. It does close programme A
on this window: Q and Gram are the same
operator plus one explicit rank-1 error.
