On ζ, C ≈ 1/(4e) to a few percent and does
not move with µ. Off ζ it is larger and
L-dependent. So 1/(4e) is a ζ coincidence
(or a pole/Γ_even coincidence), not the
definition of the kernel.

C is the last µ-stable number on ζ. It
should be read off the 2×2 pairings of
(v_arch, v_towers) against the explicit
formula — the same matrix that produced
the 30 % deficit — not guessed from
named constants.
